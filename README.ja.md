# Tsudoi · つどい

[简体中文](README.zh-CN.md) | [English](README.md) | **日本語**

公式サイト：[tsudoi.yahaha.net](https://tsudoi.yahaha.net)

1枚の背景デザインから、1枚または複数のパーソナライズされた招待状をすばやく作成できます。

Tsudoi（つどい）は、汎用的なビジュアル招待状作成ツールです。背景画像をアップロードし、テキストを追加してレイアウトを整えるだけで、高解像度の PNG をダウンロードできます。内容の異なる複数の画像が必要な場合は、CSV または TXT データを読み込み、すべての画像を生成して ZIP にまとめてダウンロードできます。

背景画像、宛先データ、生成結果は常に現在のデバイス内に保持され、サーバーへアップロードする必要はありません。

## 背景画像から完成データまで

1. 縦長、横長、または正方形の招待状背景をアップロード
2. 1つ以上のテキストボックスを追加し、キャンバス上で直接配置
3. フォント、サイズ、太さ、色、アウトライン、揃え、アンカー、固定幅を調整
4. 1枚だけ作成する場合は高解像度 PNG をダウンロード
5. 一括作成ではデータ変数を挿入し、CSV または TXT を読み込み
6. 各レコードをプレビューした後、すべての画像をローカルで生成して ZIP をダウンロード

## 主な特長

### プレビューどおりのテキストレイアウト

- テキストボックスの自由移動、固定幅、自動改行、9方向アンカーに対応
- 位置や幅を変更するとき、キャンバス端、中央、安全領域、ほかのテキストへスナップ
- プレビューと書き出しで同じ座標・描画モデルを使用し、元画像の解像度を維持
- 中国語、英語、日本語、韓国語のフォントと、言語ごとのシステムフォールバックを用意
- 簡体字中国語、繁体字中国語、英語、ドイツ語、日本語、韓国語、スペイン語、フランス語のインターフェースに対応
- システム設定、ライト、ダークの各テーマに対応し、選択内容をローカルデバイスに保存
- PWA としてインストール可能で、初回読み込み後は主要な編集・書き出し機能をオフラインでも利用可能
- 背景画像をアップロードする前は、ダークトーンのイラストをランダム表示

### 1つのテンプレートから複数の個別データを生成

通常のテキストと変数を自由に組み合わせられます。

```text
{{csv.お名前}} 様
ご案内申し上げます
番号：{{index:3}}
日付：{{date}}
```

データを読み込んだ後、任意の行を選択すると対応する内容をプレビューできます。確認後、各 PNG を生成し、現在のデバイス上で ZIP にまとめます。

### データはローカルデバイス内で処理

Tsudoi は背景画像、テンプレート、宛先リストをアップロードせず、サーバー側の画像合成にも依存しません。画像描画、CSV/TXT 解析、ZIP 作成はすべてローカルデバイスで行われ、サーバーに素材のコピーは残りません。

## 使用できる変数

変数名とコロンの前後には空白を入れられます。例：`{{ time }}`、`{{ index : 4 }}`

| 変数 | 用途 |
| --- | --- |
| `{{txt}}` | TXT の現在行を使用し、空でない各行から1枚を生成 |
| `{{csv.name}}` | CSV の現在行にある `name` 列を使用。Unicode の見出しにも対応 |
| `{{date}}` | 現在のローカル日付（`YYYY-MM-DD`） |
| `{{time}}` | 現在のローカル時刻（`HH:mm:ss`） |
| `{{datetime}}` | 現在のローカル日付と時刻 |
| `{{index}}` | 1から始まる生成番号 |
| `{{index:3}}` | 指定桁数までゼロ埋め（例：`001`）。1〜12桁に対応 |
| `{{uuid}}` | 各画像の各テキストレイヤーに固有の UUID を生成 |

## データの読み込み

- テンプレートで `{{txt}}` のみを使用する場合は TXT を読み込み、空でない各行が1枚の画像に対応
- `{{csv.見出し}}` を使用する場合は見出し行付き CSV を読み込み、参照するすべての列が必要
- 同じテンプレート内で `{{txt}}` と `{{csv.*}}` を併用することはできません
- メモリの少ないデバイスを保護するため、1回につき最大200件まで処理可能
- CSV と TXT は UTF-8 エンコーディングを推奨

## 再利用できるテンプレート

エディターはテンプレート JSON のインポートとエクスポートに対応しています。テンプレートにはキャンバスの安全領域、テキスト、変数、スタイル、幅、座標、アンカーが保存されます。背景画像や読み込んだデータは含まれないため、安全に共有して編集を続けられます。

テンプレートを読み込むと、現在の背景画像は保持され、テキストレイヤーと安全領域の余白だけが置き換わります。

## 製品上の制約

- 完成データを書き出す前に実際の背景画像が必要です。プレースホルダーのイラストは完成背景として書き出されません
- 一括生成はデバイス性能に依存し、現在は1回につき最大200枚です
- Google Fonts に接続できない場合は同じ言語のシステムフォントへ切り替わるため、表示が多少異なることがあります
- テンプレートには背景画像が含まれないため、移行時は画像ファイルを別途用意してください

## ローカル開発

Node.js 22+ と pnpm が必要です。

```bash
pnpm install
pnpm dev
```

`http://localhost:5173` を開きます。

リリース前にすべてのチェックを実行できます。

```bash
pnpm check
```

プロジェクトは完全な静的ページとして Cloudflare Pages に直接デプロイできます。デプロイ前にパッチバージョンが次の偶数へ自動的に更新されます（例：`2.3.6` から `2.3.8`）。

```bash
pnpm run deploy
```

本番ビルドでは、`https://tsudoi.yahaha.net` がcanonical URL と `og:url` のデフォルトとして使用されます。別のデプロイ先では環境変数で上書きできます。

```bash
VITE_SITE_URL=https://example.com pnpm build
```

## 製品技術

現在の Web 版は React、TypeScript、Vite、Zustand、Konva を使用しています。UI コンポーネントには Mantine、CSV 読み込みには Papa Parse、テンプレート検証には Zod、ZIP 作成には JSZip を採用しています。Cloudflare Pages は静的ファイルの配信のみを行い、ユーザー素材を受け取りません。
