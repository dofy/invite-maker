关于 Tsudoi

Tsudoi 是一款免费、开源、隐私优先的在线邀请函生成器，帮助用户从一张设计底图制作单张或整批个性化邀请函。

产品目标

Tsudoi 将可视化文字排版、CSV/TXT 数据填充与高清图片导出整合在浏览器中。用户可以直接拖动文本、调整样式和锚点，预览名单中的任意记录，并生成原图分辨率 PNG 或批量 ZIP。

设计原则

所见即所得

编辑预览与最终导出复用同一套 Canvas 场景、文字配置和百分比坐标，减少预览与成品之间的布局差异。

素材留在设备上

底图、名单、模板和生成文件都在当前浏览器内处理。编辑器会在浏览器站点数据中自动保存并恢复上一次工作区；产品不包含素材上传接口，也不依赖服务端图片渲染。

开放且可验证

项目源码与开发记录公开保存在 GitHub 仓库。产品建议、兼容性报告或其他问题可以通过 GitHub Issues 联系维护者。

技术依据

本地文件读取使用浏览器 File API，图片绘制与导出使用 Canvas API，离线支持基于 Service Worker API。相关链接指向 MDN 技术文档。

English summary

Tsudoi is a free, open-source, privacy-first visual invitation maker. Backgrounds, recipient lists, templates, and generated files are processed locally in the browser. The previous editing workspace is saved in browser site data and restored after a refresh. Source code and support are available through the project’s GitHub repository.
